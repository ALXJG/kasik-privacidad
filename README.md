# kasik-privacidad

Política de privacidad de **KASIK** — bienestar diario.

Publicada con GitHub Pages en https://alxjg.github.io/kasik-privacidad/ y
enlazada desde la ficha de Google Play y desde los ajustes de la aplicación.

El contenido de `index.html` se mantiene desde el repositorio del proyecto, en
`publicar-privacidad/index.html`. Si cambia lo que la app hace, **primero** se
actualiza aquí y después se toca la ficha de la tienda.
